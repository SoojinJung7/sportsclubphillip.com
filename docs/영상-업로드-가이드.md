# 홈 영상(PHILLIP LIFE) 올리는 법 — 동료용 가이드

> CMS의 **"업로드" 버튼은 영상엔 안 됩니다**(용량 제한 413 에러 — Pages CMS 자체 버그).
> 그래서 영상은 **① GitHub에 파일을 먼저 올리고 → ② CMS에선 그 파일을 "고르기"만** 하면 됩니다.
> (사진은 지금처럼 CMS 업로드로 그대로 하시면 됩니다. 이 방법은 **영상 전용**이에요.)

---

## 준비 (딱 1회)

사장님이 동료분 GitHub 계정을 **저장소 협업자(Collaborator)** 로 초대해야 합니다.
- 저장소: `SoojinJung7/sportsclubphillip.com`
- 초대받은 동료분은 이메일/GitHub 알림에서 **수락(Accept)** 클릭

---

## 영상 올리기 (매번 이 순서)

### 1. 영상 파일 준비
- 형식: **mp4** (webm, mov도 가능)
- 용량: **25MB 이하** 로 맞추기 ⚠️
  - GitHub 웹 업로드는 25MB까지만 됩니다.
  - 넘으면 압축하세요. (쉬운 방법: [handbrake.fr](https://handbrake.fr) 무료 프로그램 → 프리셋 `Fast 720p30` 선택 → 대부분 25MB 밑으로 줄어듦)
  - 25MB로 도저히 안 되는 큰 영상은 사장님/개발자에게 파일을 전달해 주세요.

### 2. GitHub에 영상 파일 올리기
1. 이 주소로 접속: **https://github.com/SoojinJung7/sportsclubphillip.com/tree/main/public/videos**
2. 오른쪽 위 **`Add file` → `Upload files`** 클릭
3. 영상 파일(mp4)을 화면에 **끌어다 놓기**
4. 아래로 내려서 초록색 **`Commit changes`** 버튼 클릭
5. (선택) 표지 이미지(jpg)도 있으면 같은 방식으로 함께 올리면, 영상 로딩 전에 표지로 보여집니다.

> 파일 이름은 영어/숫자로 (예: `phillip-life-02.mp4`). 한글·공백은 피해주세요.

### 3. Pages CMS에서 영상 연결
1. **https://app.pagescms.org** 접속 → GitHub 로그인 → 이 저장소 선택
2. 왼쪽 메뉴에서 **영상 (홈 PHILLIP LIFE)** 클릭
3. **영상 목록**에서 `+` 로 새 항목 추가 (또는 기존 항목 수정) — 최대 5개
4. **영상 파일** 칸을 클릭 → 뜨는 목록에서 **방금 올린 파일을 선택** 👈
   - ⚠️ 여기서 **"Upload" 버튼은 누르지 마세요** (영상은 413 에러 납니다). 반드시 **목록에서 고르기**.
5. **제목(한국어/English)**, **설명** 입력
6. 오른쪽 위 **저장(Save)** — 자동 커밋됩니다.
7. **몇 분 뒤** 사이트(sportsclubphillip.com)에 자동 반영됩니다.

## 자주 나오는 문제

| 증상 | 원인 / 해결 |
|---|---|
| CMS 업로드 시 **413 에러** | 영상을 CMS 업로드 버튼으로 올리려 함. → 위 방법대로 GitHub에 먼저 올리고 CMS에선 **고르기**. |
| GitHub 업로드가 안 됨 | 파일이 **25MB 초과**. → 압축(HandBrake `Fast 720p30`) 후 재시도. |
| 영상이 사이트에 안 보임 | ① CMS에서 저장했는지 ② 배포 완료(몇 분 소요) ③ 영상 파일 칸에 올바른 파일이 선택됐는지 확인. |
| YouTube로 올려도 되나요? | 사장님 방침상 **자체 호스팅(파일)** 을 씁니다. 유튜브 칸은 비워두세요. |
